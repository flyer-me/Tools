# Login Accessibility CMD Launch

## Alias

- Script file: `登录页面辅助功能调起cmd.bat`

## Purpose

System-level batch utility that replaces accessibility executable with `cmd.exe`.

## Run

```powershell
cmd /c ".\\scripts\\登录页面辅助功能调起cmd.bat"
```

## Risk Notice

This behavior can bypass normal sign-in flow and may violate security policy.
Use only in authorized recovery workflows.
