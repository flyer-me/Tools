DiskWriteTracker —— 硬盘写入量记录
====================================

它做什么
--------
每天自动读一次每块硬盘固件里记着的"累计写入量"，算出每天写了多少，
并在浏览器里给你一张能排序、能筛选的报表。

数字来自硬盘自己的计数器，不是软件估算，也不用联网。


怎么用
------
双击 DiskWriteTracker.exe。

会出现一个黑色的菜单窗口，这是正常的——它就是程序的界面：

  1  立即采样并刷新报表     <- 平时用这个
  2  只看报表（不采样）
  3  导出 CSV
  4  安装 / 更新每日计划任务
  5  卸载计划任务
  6  打开数据目录
  7  查看日志
  0  退出

选 1 之后会打开浏览器，显示当前报表：
  - 顶部五张卡片：今日写入、昨日写入、7 日均、累计写入、异常磁盘数
  - 中间是每天写入量的柱状图，可以切换成折线
  - 下面是明细表，点表头排序，按住 Shift 点可以叠加多个排序条件
  - 可以按磁盘、日期区间、数据质量筛选
  - "导出当前视图 CSV"把当前筛选结果存成 Excel 能直接打开的文件


装一次就不用管
--------------
选 4 安装每日计划任务（默认每天 00:05，可以改）。

这一步需要管理员权限，屏幕上会弹出授权窗口，点"是"即可。

装好之后，就算你不打开这个程序，每天也会自动记录一次。
下次打开菜单，顶部会显示任务状态和上次运行结果。

如果授权窗口没能弹出来（少数电脑的安全策略会拦），程序会打印两条命令，
复制到"以管理员身份运行"的终端里执行即可。


数据在哪
--------
就在程序旁边的 data 文件夹里：

  samples-*.jsonl   每天采样到的原始数值
  logs\             运行日志
  exports\          报表（report.html）与导出的 CSV（按下面设置的天数导出）
  settings.json     你的偏好设置

settings.json 可以用记事本直接改：

  reportDays   报表默认看最近多少天（默认 400）
  exportDays   导出默认多少天（默认 400）
  time         每日采样时间（默认 00:05）
  logDays      日志保留多少天（默认 30）

改错了也不要紧，程序会退回默认值。


数字准不准
----------
- 来自硬盘固件的累计写入计数器，是这块盘出厂以来的总写入量。
- 每天的量 = 今天最后一次读数 - 前一天最后一次读数。
- 第一次使用只记录一个起点，不会凭空造出一个增量。
- 如果计数器变小了（换了盘、刷了固件、计数器重置），当天会标成"异常"，
  不会显示负数。
- 中间有几天没开机，会把这几天的量合并到恢复那天，并标成"跨期"。
- 每块盘旁边有"数据质量"标记：可靠 / 回退 / 低可信 / 异常 / 缺失。
  标成"低可信"或"异常"时，说明这个数字本身有问题，报表会如实标出来，
  不会拿估算值凑数。


升级
----
用新版本里的 DiskWriteTracker.exe 覆盖旧的就行。

data 文件夹和每日计划任务都不用动，历史数据继续累积。

如果你以前用过更早的版本，程序旁边可能还留着几个旧文件，可以一并删掉，
不影响使用。


卸载
----
选 5 移除每日计划任务。

默认只删任务，样本数据保留。
如果连数据一起删，按提示输入 DELETE。


已知限制
--------
- 只在 Windows 10 / 11 上运行。
- 只能读直连主板的 NVMe 与 SATA 硬盘。虚拟磁盘、
  以及某些 RAID 卡后面挂的盘不提供这个计数器，会读不到。
- 报表是本地网页文件，受浏览器安全限制，页面里不能直接触发采样；
  要采样请回到这个菜单选 1。
- 全程不联网，不上传任何数据。


彻底删除
--------
把整个文件夹删掉即可。程序不写注册表，不装服务，
除了每日计划任务（用菜单 5 移除）以外不在系统里留东西。
