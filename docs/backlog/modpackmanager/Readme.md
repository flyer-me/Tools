
### 文件清单与内容指引

1. **`01_Project_Goals_and_Architecture.md` (项目目标与总体架构体系)**
   * **第 1 章：项目目标** —— 明确了系统的 6 大核心业务诉求，并从“可维护性”、“性能与响应力”以及“设计简单性”三个维度推导出了项目的质量属性目标（ADD 核心）。
   * **第 2 章：总体架构** —— 采用了实用主义的分层架构（UI层、Core核心层、Adapter防腐层、Storage存储层），明确规定了 4 个物理项目（Projects）之间的单向依赖关系，杜绝无意义的过度分包。

2. **`02_Modules_and_Data_Flow.md` (模块划分与核心数据流)**
   * **第 3 章：模块划分** —— 精简归纳了 UI 呈现、扫描引擎、冲突去重、依赖解析、网络下载等核心模块的职责分配与核心技术选型（如 WPF 虚拟化）。
   * **第 4 章：核心数据流向** —— 用清晰的文本管道图详细勾勒出“Mod 本地扫描/去重/冲突检测”以及“远程仓库依赖自动补全/下载”的核心运行时数据流。

3. **`03_Interfaces_and_Directory_Structure.md` (核心接口契约与工程目录结构)**
   * **第 5 章：核心接口设计** —— 给出了干净、符合 ISP（接口隔离原则）的 C# 核心接口定义（包含 `IKKManagerAdapter`、`IModScanner`、`IModDependencyResolver`、`IModRepository` 等），并附带了详细的异步编程和设计注释。
   * **第 6 章：全局目录结构** —— 提供了完整的、无胶水代码的工程树状结构目录，精确到每一个核心业务文件夹与 DI（依赖注入）入口的定位。

4. **`04_Development_and_ADR.md` (敏捷开发顺序与架构决策记录)**
   * **第 7 章：开发顺序（迭代路线）** —— 为 1~2 人团队量身定制的“串行破局法”，划分为 4 个清晰的交付阶段（Phase 1~4），帮助你们端到端快速点亮功能闭环。
   * **第 8 章：架构决策记录 (ADR)** —— 记录了 4 个最关键的技术决策及深度理由：
     * **ADR-001**：选用 `CommunityToolkit.Mvvm`（利用 C# 编译期源生成器，彻底消灭样板代码）。
     * **ADR-002**：选用 `LiteDB` 无模式单文件嵌入式数据库（免去 EF Core 频繁 Migration 的痛苦，分发成本为零）。
     * **ADR-003**：对 `KKManager Core` 实施严格的适配器隔离（建立坚固的防腐层，保护主程序不随外部依赖而崩溃或重构）。
     * **ADR-004**：全线选用 `.NET 异步流（IAsyncEnumerable<T>）` 传递文件扫描流（实现流式消费，内存占用极低且 UI 绝不卡顿）。
